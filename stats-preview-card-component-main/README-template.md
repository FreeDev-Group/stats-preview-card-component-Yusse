### What I learned

I have learned to make this page responsive using CSS styling : 

@media (max-width: 900px) {
  .card {
    flex-direction: column-reverse;
    text-align: center;
  }
  .card-text {
    width: 100%;
    padding: 40px;
    text-align: center;
  }
  .stats {
    justify-content: center;
  }
  .card-image {
    width: 100%;
    height: 300px;
  }
}
